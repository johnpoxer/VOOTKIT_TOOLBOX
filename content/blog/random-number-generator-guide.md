Choose whether repeats are permitted according to what the numbers represent.

Use the [Random Number Generator](/tools/everyday/random-number-generator/) alongside this illustrative example.

## A practical example

For a die simulation, repeated values from one to six are valid. For assigning five distinct seats numbered one to ten, use unique results instead. A request for eleven unique numbers from that ten-number range is impossible, so first compare the requested count with the available range.

## Check the result

Record the range and repeat rule before drawing. Do not rerun a selection simply because the first result is inconvenient; that changes how the selection procedure works.

## Try a comparison

Switch off uniqueness for a die simulation and notice that repeated rolls become possible. Switch it on for distinct seat assignments. Neither setting is universally more fair; the appropriate one follows the rule for the task.

## What this does not establish

This general-purpose random tool is not a source of credentials or a certified lottery mechanism. Use an appropriate security generator for secrets.
