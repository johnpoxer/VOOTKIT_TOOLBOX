Use an expression calculator to check arithmetic while preserving the meaning of the original problem.

Use the [Math Solver](/tools/everyday/math-solver/) alongside this illustrative example.

## A practical example

For a subtotal of 120 with a 15% addition, enter `120 * (1 + 0.15)`, which equals 138. Entering `120 + 15` instead gives 135 because the second expression adds a fixed amount, not a percentage. Parentheses make the intended order visible.

## Check the result

Check the supported input syntax shown by the tool before pasting mathematical notation. Treat a syntax error as an instruction to simplify the expression, not as evidence that the mathematical problem has no answer.

## Try a comparison

Compare `120 * (1 + 0.15)` with `(120 + 15) * 1`. They give 138 and 135. A calculator can evaluate both correctly while only one represents the intended percentage problem; deciding which expression models the task remains part of the work.

## What this does not establish

Numeric evaluation is not a proof or a symbolic derivation. Keep units and intermediate assumptions in your notes, especially for a result used elsewhere.
