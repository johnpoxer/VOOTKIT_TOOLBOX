Compare typing sessions using accuracy and consistent conditions.

Use the [Typing Speed Test](/tools/everyday/typing-test/) alongside this illustrative example.

## A practical example

Run the same duration on the same keyboard over several sessions, then compare accuracy before the displayed speed. A fast run with many mistakes may take longer to turn into usable text once corrections are included. Record the passage type, because unfamiliar punctuation and names can change the difficulty.

## Check the result

Avoid comparing a memorised passage with a new passage as though only skill changed. Check that interruptions did not stop or distort the timing.

## Try a comparison

Repeat on a different day without first rehearsing the passage. Compare several results rather than treating one unusually fast or distracted run as a baseline. For your own improvement record, note accuracy, speed and the conditions of each session.

## What this does not establish

A browser score is practice feedback, not a certified employment assessment. The result does not measure every part of writing or editing work.
