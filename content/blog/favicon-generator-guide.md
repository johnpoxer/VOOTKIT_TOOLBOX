## Decide what the finished file must do

Before using Favicon Generator, identify the destination: email, upload portal, website, print, archive, application or internal review. That choice controls format, dimensions, quality and what must remain editable or searchable. A technically successful favicon generator operation can still produce the wrong result for its destination.

For Favicon Generator, prepare:

- **Simple source mark.** Use the reviewed source rather than a forwarded or compressed copy.
- **Square canvas.** Confirm this against the destination requirement before processing.
- **High contrast.** Record the choice so the result can be reproduced later.
- **Transparent background.** Record the choice so the result can be reproduced later.
- **Target sizes.** Record the choice so the result can be reproduced later.

## Choose settings from the destination backward

Start with **target sizes**, because it defines what the recipient or platform will accept. Then set **square canvas** only as high as that job needs. Maximum quality, resolution or page size is not automatically safer: it can make the output slower, harder to send and no more useful at its real display size.

For Favicon Generator, make a second test version when you are unsure. Change one setting only, compare both outputs at the size the recipient will use, and keep the smaller or simpler version only when meaningful detail and required behaviour remain intact. This one-variable comparison is more dependable than changing format, quality and dimensions together.

## Step-by-step workflow

1. Preserve the original and work from a clearly named copy.
2. Open [Favicon Generator](/tools/images/favicon-generator/) and add the intended source file or files.
3. Set **square canvas** for the actual destination rather than choosing the maximum automatically.
4. Process one representative result first when the source contains mixed pages or a batch of different images.
5. Inspect the areas most likely to fail: small text, faces, signatures, transparent edges, page order or fine lines.
6. Export with a descriptive filename and reopen it outside the tool before sending or replacing anything.

## What changes—and what does not

Tiny icons need simplified geometry. Text, thin strokes and photographic detail disappear at browser-tab size.

The Favicon Generator result should be judged by fitness for purpose. Compare the output with the source at normal viewing size and at 100% zoom, then test any behaviour the destination needs: text selection, transparency, links, form fields, print margins or platform acceptance.

## Common mistakes

- **Shrinking the full logo.** This usually creates the largest avoidable failure.
- **No padding.** Check this in the first test export.
- **Weak dark-mode contrast.** Add it to the final review rather than assuming the tool can infer it.
- **Testing only the large preview.** Add it to the final review rather than assuming the tool can infer it.

## Quality and privacy checklist

- Keep the original image until the recipient or destination accepts the new version.
- Verify **simple source mark** and **target sizes** against the job requirement.
- Reopen the exported file and confirm its type, dimensions or page count.
- Inspect content that carries meaning: names, totals, signatures, labels, faces and fine edges.
- Remove private pages, metadata or visual details only with a method that truly removes them.
- Use a new filename so the source and output cannot be confused.

## Frequently asked questions

### Does Favicon Generator upload my file?

The Favicon Generator operation runs in the browser on your device. The page itself and its processing libraries must load, but Vootkit does not need to upload the source file to perform this operation.

### Should I delete the original after the export works?

Not immediately. Keep the original until the Favicon Generator output has been reopened, checked and accepted by its destination. This operation and any later conversion, cropping, compression, redaction or page edit can discard information that cannot be recreated.

### Why can the output look different from the source?

Format capabilities, fonts, colour handling, transparency, compression, rendering scale and page geometry can all affect appearance. For Favicon Generator, check **square canvas** and the limitation explained above first.
