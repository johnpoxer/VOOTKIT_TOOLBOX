Crop Image helps you remove distractions and fit a required frame without stretching the subject. The fastest workflow is not the one with the fewest clicks; it is the one that preserves the right source, uses settings chosen for the destination and includes a deliberate check of the export.

## What the Crop Image does

Crop to a ratio or exact selection. Open the [Crop Image](/tools/images/crop-image/) to follow the workflow in this guide.

Crop Image performs this file operation in your browser after its required code has loaded. Vootkit does not need to upload the source for this operation, but the exported image still deserves the same privacy care as the original.

## Decide what the finished file must do

Before using Crop Image, identify the destination: email, upload portal, website, print, archive, application or internal review. That choice controls format, dimensions, quality and what must remain editable or searchable. A technically successful crop image operation can still produce the wrong result for its destination.

For Crop Image, prepare:

- **Original image.** Use the reviewed source rather than a forwarded or compressed copy.
- **Target aspect ratio.** Confirm this against the destination requirement before processing.
- **Final pixel size.** Record the choice so the result can be reproduced later.
- **Safe area.** Record the choice so the result can be reproduced later.
- **Focal point.** Record the choice so the result can be reproduced later.

## Choose settings from the destination backward

Start with **focal point**, because it defines what the recipient or platform will accept. Then set **target aspect ratio** only as high as that job needs. Maximum quality, resolution or page size is not automatically safer: it can make the output slower, harder to send and no more useful at its real display size.

For Crop Image, make a second test version when you are unsure. Change one setting only, compare both outputs at the size the recipient will use, and keep the smaller or simpler version only when meaningful detail and required behaviour remain intact. This one-variable comparison is more dependable than changing format, quality and dimensions together.

## Step-by-step workflow

1. Preserve the original and work from a clearly named copy.
2. Open [Crop Image](/tools/images/crop-image/) and add the intended source file or files.
3. Set **target aspect ratio** for the actual destination rather than choosing the maximum automatically.
4. Process one representative result first when the source contains mixed pages or a batch of different images.
5. Inspect the areas most likely to fail: small text, faces, signatures, transparent edges, page order or fine lines.
6. Export with a descriptive filename and reopen it outside the tool before sending or replacing anything.

## Worked example

A landscape portrait is cropped to 1:1 for a profile card while keeping eyes above centre and enough space around the face for a circular display.

This scenario tests Crop Image against a concrete requirement. If **original image** or **target aspect ratio** changes, keep the first result as a baseline so you can identify which choice affected quality, size or usability.

## What changes—and what does not

Cropping discards pixels outside the frame. It changes composition, not perspective, and cannot restore a subject already cut off.

The Crop Image result should be judged by fitness for purpose. Compare the output with the source at normal viewing size and at 100% zoom, then test any behaviour the destination needs: text selection, transparency, links, form fields, print margins or platform acceptance.

## Common mistakes

- **Cropping before choosing the destination ratio.** This usually creates the largest avoidable failure.
- **Cutting joints or text.** Check this in the first test export.
- **Placing faces at edges.** Add it to the final review rather than assuming the tool can infer it.
- **Overwriting the original.** Add it to the final review rather than assuming the tool can infer it.

## Quality and privacy checklist

- Keep the original image until the recipient or destination accepts the new version.
- Verify **original image** and **focal point** against the job requirement.
- Reopen the exported file and confirm its type, dimensions or page count.
- Inspect content that carries meaning: names, totals, signatures, labels, faces and fine edges.
- Remove private pages, metadata or visual details only with a method that truly removes them.
- Use a new filename so the source and output cannot be confused.

## Frequently asked questions

### Does Crop Image upload my file?

The Crop Image operation runs in the browser on your device. The page itself and its processing libraries must load, but Vootkit does not need to upload the source file to perform this operation.

### Should I delete the original after the export works?

Not immediately. Keep the original until the Crop Image output has been reopened, checked and accepted by its destination. This operation and any later conversion, cropping, compression, redaction or page edit can discard information that cannot be recreated.

### Why can the output look different from the source?

Format capabilities, fonts, colour handling, transparency, compression, rendering scale and page geometry can all affect appearance. For Crop Image, check **target aspect ratio** and the limitation explained above first.
