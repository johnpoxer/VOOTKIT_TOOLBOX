# Website maintenance — 6 November 2026

The owner reported that the workflow builder does not work and requested its withdrawal. This revision removes workflow links from desktop/mobile navigation, home promotions, tool-directory promotions, article recommendations, help, files and account pages. Saved workflows are no longer sold as a Pro benefit, and workflow notification controls are withdrawn. Duplicate Guides/Blog links pointing to the same destination were consolidated.

Bookmarked workflow URLs temporarily redirect to the tools directory. A noindex, advertising-free notice replaces the builder file as a fallback. The workflow JavaScript is not loaded by this page. Builder implementation files and saved browser data remain intact so a separately tested restoration is possible. GitHub Actions are unrelated deployment infrastructure and are retained.

Checks: production build; 1,718 HTML pages scanned for workflow links/claims; 198 articles checked for identical bodies and five-word-shingle Jaccard similarity of at least 0.65; homepage raster images compared by file hash. No duplicate article bodies, highly similar article pairs or repeated homepage image files were found. SEO, editorial examples, billing and usage tests passed. Static tool-registry inspection found matching implementations for 258 live tool IDs. These checks do not replace running every tool with representative files, external plagiarism review, accessibility review or production consent testing.

Google's low-value-content message does not identify workflow failure as its cause. Withdrawing a broken feature and correcting claims improves the experience but does not ensure approval. Ongoing original work, useful examples, honest limitations and genuine visitor feedback remain necessary. No AdSense reapplication was submitted and no paid server was purchased.
